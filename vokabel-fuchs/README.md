# Vokabel-Fuchs

Englisch-Vokabeltrainer (Seiten 170–186) als Web-App fürs iPhone.

## So kommt die App auf GitHub Pages

1. Bei [github.com](https://github.com) anmelden und oben rechts **+ → New repository** wählen.
2. Name: `vokabel-fuchs`, Sichtbarkeit **Public**, dann **Create repository**.
3. Auf der neuen Seite **uploading an existing file** anklicken und alle Dateien aus diesem Ordner hineinziehen
   (`index.html`, `apple-touch-icon.png`, `icon-512.png`, `manifest.webmanifest`, `README.md`). Dann **Commit changes**.
4. **Settings → Pages**: Bei *Source* „Deploy from a branch“, Branch `main`, Ordner `/ (root)`, **Save**.
5. Nach ein bis zwei Minuten steht dort die Adresse, z. B. `https://DEIN-NAME.github.io/vokabel-fuchs/`.

## Aufs iPhone

1. Die Adresse in **Safari** öffnen.
2. **Teilen** → **Zum Home-Bildschirm** → **Hinzufügen**.
3. Ab jetzt die App immer über das Fuchs-Icon starten. Der Lernstand wird auf dem iPhone gespeichert,
   und zwar getrennt von Safari. Also nicht abwechselnd in Safari und über das Icon üben.

## Neue Version hochladen

Im Repository **Add file → Upload files** wählen, die neue `index.html` hineinziehen und **Commit changes** klicken.
Die alte Datei wird dabei ersetzt. Der Lernstand auf dem iPhone bleibt erhalten.

## Hinweis

Die Adresse ist öffentlich, aber nicht verlinkt. Wer sie nicht kennt, findet die App praktisch nicht.
Der Lernstand liegt nur auf dem eigenen Gerät und ist für niemanden sonst sichtbar.
